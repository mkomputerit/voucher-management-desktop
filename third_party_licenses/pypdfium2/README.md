# pypdfium2 license texts

These files are copied verbatim from the upstream **pypdfium2 4.30.0** source
tag:

- `LICENSES/Apache-2.0.txt`
- `LICENSES/BSD-3-Clause.txt`

Upstream project: `pypdfium2-team/pypdfium2`

They accompany the packaged license/third-party notices collected from the
installed pypdfium2/PDFium distribution. They are retained here so the Windows
release artifact does not depend on the wheel exposing the dual-license texts
through Python package metadata.
