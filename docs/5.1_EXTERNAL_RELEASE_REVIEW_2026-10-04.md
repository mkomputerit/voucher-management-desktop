## Finding discovered and closed during the review

### MEDIUM — uncertain-create recovery selection

The rare uncertain-create reconciliation callback could still re-select recovered
voucher candidates after a successful operator decision. That contradicted the
global invariant that a successful voucher-changing operation clears the shared
Home/Voucher selection and refreshes affected projections.

Resolution:

- both association and rejection paths now use the centralized post-operation
  finalizer;
- recovered vouchers no longer remain selected;
- Home/Voucher/report/threshold projections refresh consistently;
- regression tests cover both operator decisions.

A first CI run after the correction exposed only an incomplete test fake:
**811 tests passed and 1 fixture failed**. The fixture was corrected without
changing application code. The exact-head final run then passed completely.
